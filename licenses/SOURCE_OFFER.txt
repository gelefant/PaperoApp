Papero distributes the standalone DjVuLibre command-line executables (`ddjvu`,
`djvused`, `djvutxt`) and their accompanying runtime shared libraries as an
independent mere aggregation alongside the Papero application (`MIT OR
Apache-2.0`). Papero executes these tools exclusively as separate operating
system child processes and does not link `libdjvulibre` into Papero's Rust or
JavaScript code.
